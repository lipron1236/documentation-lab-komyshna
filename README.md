# TutorFind

## Опис проєкту
TutorFind — це платформа для пошуку репетиторів з різних предметів. Система вирішує проблему, коли учню або студенту складно знайти кваліфікованого репетитора поблизу або онлайн, а репетиторам — знайти учнів.

## Основні функції
- Пошук репетиторів за предметом, містом і ціною.
- Перегляд профілю репетитора з досвідом і відгуками.
- Запис на пробне заняття онлайн.
- Чат між учнем і репетитором.
- Система відгуків та рейтингів.

## Для кого цей продукт
Продукт призначений для школярів, студентів і дорослих, які хочуть знайти репетитора, а також для репетиторів, які шукають учнів.
